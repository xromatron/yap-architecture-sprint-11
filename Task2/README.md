2. Логика разделения на домены:

Домены:
1. Интеграция и хранения данных (DWH, Data Lake, ETL, интеграционная шина)
- управление потоками централизовано
- удобное и прозрачная интеграция новых доменов и сервисов
2. Фин.сервисы (интерфейс для фин.партнеров)
- разделение ответственности
- независимое развитие и масштабирование
- снижение рисков для безопасности фин.данных
3. Мед.сервисы (интерфейс для операторов)
- разделение ответственности
- независимое развитие и масштабирование
- снижение рисков для безопасности мед.данных
4. Бизнес аналитика (витрины данных, портал самообслуживания)
- быстрое формирование отчетов
- возможность самостоятельно определять структура отчетов
5. ИИ (сервисы и хранилище обработанных данных)
- обработка данных с помощью машинного обучения
- повышение качества диагностики и выдачи рекомендаций
